# mapping_elf 畫布軌跡轉導航路線演算法規格書

本文件定義針對 `mapping_elf` 專案中將畫布（Canvas）手繪軌跡或幾何預設圖案轉化為實體道路導航路線的**「五階段形狀擬合導航路由演算法（Shape-Constrained Routing Algorithm）」**。

---

## 1. 問題背景與診斷

將隨意繪製的 $2\text{D}$ 向量圖形直接轉換為實體路網導航時，傳統「取樣點 $\to$ 導航 API」的作法會面臨以下四大結構性缺陷：

| 缺陷現象 | 成因分析 | 解決方案 |
| :--- | :--- | :--- |
| **截彎取直（Shortcutting）** | 導航引擎（OSRM / Valhalla）預設追求時間／距離極小化，自動忽略曲線弧度與非最短路徑。 | **曲率自適應錨點插值 + 走廊限制權重（Corridor Penalty）** |
| **死巷折返毛刺（Spurs）** | 畫布取樣點落於建築物內或單行道對向，強制投影（Snap）導致路線鑽入死巷又立即 $180^\circ$ 折返。 | **HMM 維特比地圖匹配（Viterbi Map Matching）+ 拓撲去毛刺後處理** |
| **迴圈與自交坍縮（Loop Collapse）** | 愛心底部、8 字形交叉點等幾何特徵點距離過近，被路由引擎直接判斷為原地抵達並提早閉合。 | **特徵拐點／自交點筆畫切分（Stroke Phase Segmentation）** |
| **長寬比例失真** | 畫布 $(x, y)$ 線性映射至 $(\text{lng}, \text{lat})$ 時，未考慮高緯度經度線收縮與曼哈頓路網繞行係數。 | **局部切平面 $\cos(\text{lat})$ 餘弦補償 + 繞行係數 $\eta$ 縮放** |

---

## 2. 演算法架構與數學模型

```
[ Canvas 手繪輸入 (x, y) ]
            │
            ▼
┌────────────────────────────────────────┐
│ 階段一：Chaikin 平滑濾波 + 曲率自適應取樣 │
└────────────────────────────────────────┘
            │
            ▼
┌────────────────────────────────────────┐
│ 階段二：等比例地理投影 + 緯度餘弦校正   │
└────────────────────────────────────────┘
            │
            ▼
┌────────────────────────────────────────┐
│ 階段三：筆畫拓撲切分 + HMM 路網匹配    │
└────────────────────────────────────────┘
            │
            ▼
┌────────────────────────────────────────┐
│ 階段四：拓撲去毛刺 (Spur Pruning)      │
└────────────────────────────────────────┘
            │
            ▼
┌────────────────────────────────────────┐
│ 階段五：離散 Fréchet 相似度評估與輸出  │
└────────────────────────────────────────┘
```

### 階段一：軌跡去噪與曲率自適應重採樣（Curvature-Adaptive Resampling）

1. **Chaikin 平滑演算法**：消除使用者手繪時的微小高頻手抖：
   $$Q_i = \frac{3}{4} P_i + \frac{1}{4} P_{i+1}, \quad R_i = \frac{1}{4} P_i + \frac{3}{4} P_{i+1}$$
2. **特徵拐點檢測（Corner Detection）**：
   計算相鄰向量的夾角餘弦：
   $$\cos\theta_i = \frac{\vec{v}_{i-1} \cdot \vec{v}_i}{\|\vec{v}_{i-1}\| \|\vec{v}_i\|}$$
   當 $\theta_i > \theta_{\text{corner}}$（預設 $38^\circ$）時，標記為**硬性錨點（Hard Anchor）**，禁止在後續抽樣中被簡化或平滑消除。
3. **弧長自適應插值**：在相鄰硬性錨點之間，以設定的地理步長 $\Delta s$（例如 $80\text{m} \sim 120\text{m}$）進行均勻插值，生成**軟性引導點（Soft Guide Points）**。

### 階段二：等比例地理投影與網格校正（Isotropic Geo-Projection）

設正規化畫布座標為 $(\hat{x}_i, \hat{y}_i) \in [-0.5, 0.5]^2$，目標地圖中心為 $(\text{lat}_0, \text{lng}_0)$：

1. **路網繞行係數（Detour Factor）補償**：
   真實城市道路非直線，平均繞行係數 $\eta \approx 1.25 \sim 1.35$。若目標總長度為 $L_{\text{target}}$，而畫布正規化幾何長度為 $L_{\text{norm}}$，則尺度轉換因子 $S$ 為：
   $$S = \frac{L_{\text{target}}}{\eta \cdot L_{\text{norm}}}$$
2. **切平面經緯度轉換**：
   支援任意旋轉角 $\phi$（對齊當地路網主軸）：
   $$\begin{bmatrix} u_i \\ v_i \end{bmatrix} = S \begin{bmatrix} \cos\phi & -\sin\phi \\ \sin\phi & \cos\phi \end{bmatrix} \begin{bmatrix} \hat{x}_i \\ -\hat{y}_i \end{bmatrix}$$
   $$\text{lat}_i = \text{lat}_0 + \left( \frac{v_i}{R_{\text{earth}}} \right) \cdot \frac{180}{\pi}$$
   $$\text{lng}_i = \text{lng}_0 + \left( \frac{u_i}{R_{\text{earth}} \cdot \cos(\text{lat}_0 \cdot \frac{\pi}{180})} \right) \cdot \frac{180}{\pi}$$

### 階段三：筆畫拓撲切分與 HMM 路網擬合

為避免封閉線圈（如心形、圓形）起點與終點過近被直接連通短路：
1. **分段切分（Segmentation）**：在硬性拐點與自交點將連續路徑切分為 $K$ 個子筆畫段落。
2. **HMM 地圖匹配（Hidden Markov Model Map Matching）**：
   對每個子段落賦予虛擬時間戳記序列 $t_i = t_0 + \frac{s_i}{v_{\text{walk}}}$（其中 $v_{\text{walk}} = 1.4\text{ m/s}$），並設定自適應搜尋半徑：硬錨點給予嚴格半徑（$25\text{m}$），軟引導點給予寬鬆半徑（$50\text{m}$）。
   呼叫支援維特比匹配的 API（如 OSRM `/match/v1`），若匹配失敗則平滑降級為分段導航（`/route/v1`）。

### 階段四：拓撲去毛刺（Spur Pruning）

導航引擎在吸附（Snap）道路時，常產生探入死巷又折返的「刺狀路徑」：
* 遍歷路徑頂點，若存在子序列 $P_i \to \dots \to P_j$ 滿足：
  $$\text{dist}(P_i, P_j) < 14\text{m} \quad \text{且} \quad \sum_{k=i}^{j-1} \text{dist}(P_k, P_{k+1}) < 85\text{m}$$
  且該折返頂點並非使用者繪製的硬性拐點，則將 $P_{i+1} \dots P_j$ 節點剔除，直接將 $P_i$ 與 $P_j$ 合併。

### 階段五：形狀相似度評估（Discrete Fréchet Distance）

將生成的實體路線正規化回同維度空間，計算離散弗雷歇距離 $\delta_{\text{dF}}$ 與相鄰切線方向餘弦相似度 $C_{\text{dir}}$，輸出綜合分數 $F_{\text{score}} \in [0, 100]$：
$$F_{\text{score}} = 0.65 \cdot 100 \exp(-3.2 \cdot \delta_{\text{dF}}) + 0.35 \cdot \left( \frac{C_{\text{dir}} + 1}{2} \cdot 100 \right)$$

## 3. 模組完整實作程式碼

此模組設計為獨立的 ES Module（`shapeRouteMatcher.js`），不依賴外部肥大套件，僅需傳入自定義的導航請求轉接器（Adapter）：

```javascript
/**
 * Shape-Constrained Navigation Route Generator for mapping_elf
 * Fits a 2D canvas drawing pattern onto a real-world road network while
 * preserving geometric fidelity, corner features, and loop topology.
 */

const EARTH_RADIUS_M = 6371008.8;
const DEG_TO_RAD = Math.PI / 180;
const RAD_TO_DEG = 180 / Math.PI;

/**
 * Main entry point: Converts raw canvas strokes into a shape-matched road route.
 *
 * @param {Array<{x: number, y: number}>} canvasPoints - Raw points from drawing canvas
 * @param {Object} options - Configuration parameters
 * @param {{lat: number, lng: number}} options.center - Target map center coordinates
 * @param {number} [options.targetDistanceM=5000] - Desired total route distance in meters
 * @param {number} [options.detourFactor=1.32] - Typical road network detour multiplier
 * @param {number} [options.sampleStepM=90] - Resampling interval along the curve in meters
 * @param {number} [options.cornerAngleDeg=38] - Turning angle threshold for hard anchors
 * @param {number} [options.rotationDeg=0] - Rotation angle in degrees to align with street grid
 * @param {Function} options.routingAdapter - Async function(waypoints, isMatchMode) => Array<{lat, lng}>
 * @returns {Promise<{route: Array<{lat: number, lng: number}>, anchors: Array, similarityScore: number, distanceM: number}>}
 */
export async function generateShapeMatchedRoute(canvasPoints, options) {
  const {
    center,
    targetDistanceM = 5000,
    detourFactor = 1.32,
    sampleStepM = 90,
    cornerAngleDeg = 38,
    rotationDeg = 0,
    routingAdapter,
  } = options;

  if (!canvasPoints || canvasPoints.length < 2) {
    throw new Error('At least 2 canvas points are required to form a pattern.');
  }

  // 1. Smooth jitter & normalize
  const smoothed = chaikinSmooth(canvasPoints, 2);
  const { normalizedPoints, normArcLength } = normalizeCanvasGeometry(smoothed);

  if (normArcLength < 1e-6) {
    throw new Error('Drawing pattern has zero geometric length.');
  }

  // 2. Rescale with road network detour compensation
  const geometricTargetLengthM = targetDistanceM / detourFactor;
  const scaleMeters = geometricTargetLengthM / normArcLength;
  const stepNorm = sampleStepM / scaleMeters;

  const sampledPattern = resampleWithCurvatureAnchors(
    normalizedPoints,
    stepNorm,
    cornerAngleDeg
  );

  // 3. Project to geographic coordinate space
  const geoWaypoints = projectToGeo(
    sampledPattern,
    center,
    scaleMeters,
    rotationDeg
  );

  // 4. Split strokes at sharp corners to prevent shortcutting / loop collapse
  const segments = splitIntoTopologicalSegments(geoWaypoints);
  const rawRoutedSegments = [];

  for (const segment of segments) {
    const matchedSegment = await fitSegmentToRoadNetwork(segment, routingAdapter);
    rawRoutedSegments.push(matchedSegment);
  }

  const stitchedRoute = stitchSegments(rawRoutedSegments);

  // 5. Post-processing: prune dead-end spurs
  const cleanedRoute = pruneSpursAndSpikes(stitchedRoute, geoWaypoints, 85);

  // 6. Similarity evaluation
  const similarityScore = evaluateShapeSimilarity(geoWaypoints, cleanedRoute);
  const distanceM = computeGeoPathLength(cleanedRoute);

  return {
    route: cleanedRoute,
    anchors: geoWaypoints,
    similarityScore,
    distanceM,
  };
}

/* ==========================================================================
 * Geometry & Resampling Helpers
 * ========================================================================== */

function chaikinSmooth(points, iterations = 2) {
  let current = points.map((p) => ({ x: p.x, y: p.y }));
  const isClosed =
    Math.hypot(
      current[0].x - current[current.length - 1].x,
      current[0].y - current[current.length - 1].y
    ) < 12;

  for (let iter = 0; iter < iterations; iter++) {
    if (current.length < 3) break;
    const next = [current[0]];
    for (let i = 0; i < current.length - 1; i++) {
      const p0 = current[i];
      const p1 = current[i + 1];
      next.push(
        { x: 0.75 * p0.x + 0.25 * p1.x, y: 0.75 * p0.y + 0.25 * p1.y },
        { x: 0.25 * p0.x + 0.75 * p1.x, y: 0.25 * p0.y + 0.75 * p1.y }
      );
    }
    next.push(isClosed ? { ...next[0] } : current[current.length - 1]);
    current = next;
  }
  return current;
}

function normalizeCanvasGeometry(points) {
  let minX = Infinity, maxX = -Infinity;
  let minY = Infinity, maxY = -Infinity;

  for (const p of points) {
    if (p.x < minX) minX = p.x;
    if (p.x > maxX) maxX = p.x;
    if (p.y < minY) minY = p.y;
    if (p.y > maxY) maxY = p.y;
  }

  const width = maxX - minX;
  const height = maxY - minY;
  const maxSpan = Math.max(width, height, 1e-6);
  const cx = (minX + maxX) / 2;
  const cy = (minY + maxY) / 2;

  const normalizedPoints = [];
  let normArcLength = 0;

  for (let i = 0; i < points.length; i++) {
    // Invert Y so that canvas downward direction matches geo southward
    const nx = (points[i].x - cx) / maxSpan;
    const ny = -(points[i].y - cy) / maxSpan;
    normalizedPoints.push({ x: nx, y: ny });

    if (i > 0) {
      normArcLength += Math.hypot(
        nx - normalizedPoints[i - 1].x,
        ny - normalizedPoints[i - 1].y
      );
    }
  }

  return { normalizedPoints, normArcLength };
}

function resampleWithCurvatureAnchors(points, stepDist, cornerAngleDeg) {
  const simplified = simplifyRDP(points, stepDist * 0.18);
  const cornerCosThreshold = Math.cos(cornerAngleDeg * DEG_TO_RAD);

  const hardAnchorIndices = new Set([0, simplified.length - 1]);
  for (let i = 1; i < simplified.length - 1; i++) {
    const prev = simplified[i - 1];
    const curr = simplified[i];
    const next = simplified[i + 1];

    const v1x = curr.x - prev.x, v1y = curr.y - prev.y;
    const v2x = next.x - curr.x, v2y = next.y - curr.y;
    const len1 = Math.hypot(v1x, v1y);
    const len2 = Math.hypot(v2x, v2y);

    if (len1 > 1e-5 && len2 > 1e-5) {
      const cosAngle = (v1x * v2x + v1y * v2y) / (len1 * len2);
      if (cosAngle < cornerCosThreshold) {
        hardAnchorIndices.add(i);
      }
    }
  }

  const anchorList = Array.from(hardAnchorIndices).sort((a, b) => a - b);
  const resampled = [];

  for (let k = 0; k < anchorList.length - 1; k++) {
    const startIdx = anchorList[k];
    const endIdx = anchorList[k + 1];
    const subPoly = simplified.slice(startIdx, endIdx + 1);
    const subLength = compute2DLength(subPoly);

    const numSegments = Math.max(1, Math.round(subLength / stepDist));
    for (let s = 0; s < numSegments; s++) {
      const targetDist = (s / numSegments) * subLength;
      const pt = interpolateAlong2DPolyline(subPoly, targetDist);
      resampled.push({
        x: pt.x,
        y: pt.y,
        isCorner: s === 0,
      });
    }
  }

  const lastPt = simplified[simplified.length - 1];
  resampled.push({ x: lastPt.x, y: lastPt.y, isCorner: true });
  return resampled;
}

function projectToGeo(sampledPattern, center, scaleMeters, rotationDeg) {
  const radRot = rotationDeg * DEG_TO_RAD;
  const cosR = Math.cos(radRot);
  const sinR = Math.sin(radRot);
  const cosLat = Math.max(0.1, Math.cos(center.lat * DEG_TO_RAD));

  return sampledPattern.map((pt, index) => {
    const eastM = (pt.x * cosR - pt.y * sinR) * scaleMeters;
    const northM = (pt.x * sinR + pt.y * cosR) * scaleMeters;

    const dLat = (northM / EARTH_RADIUS_M) * RAD_TO_DEG;
    const dLng = (eastM / (EARTH_RADIUS_M * cosLat)) * RAD_TO_DEG;

    return {
      lat: center.lat + dLat,
      lng: center.lng + dLng,
      isCorner: Boolean(pt.isCorner),
      index,
    };
  });
}

function splitIntoTopologicalSegments(geoWaypoints) {
  const segments = [];
  let currentSegment = [geoWaypoints[0]];

  for (let i = 1; i < geoWaypoints.length; i++) {
    const pt = geoWaypoints[i];
    currentSegment.push(pt);

    const isLast = i === geoWaypoints.length - 1;
    if ((pt.isCorner && currentSegment.length >= 3) || currentSegment.length >= 25) {
      if (!isLast) {
        segments.push(currentSegment);
        currentSegment = [pt];
      }
    }
  }

  if (currentSegment.length >= 2) {
    segments.push(currentSegment);
  } else if (segments.length > 0 && currentSegment.length === 1) {
    segments[segments.length - 1].push(currentSegment[0]);
  }

  return segments;
}

async function fitSegmentToRoadNetwork(segmentWaypoints, routingAdapter) {
  try {
    const matched = await routingAdapter(segmentWaypoints, true);
    if (matched && matched.length >= 2) {
      return matched;
    }
  } catch (_err) {
    // Graceful fallback to route API
  }

  const decimated = segmentWaypoints.filter(
    (pt, idx) => pt.isCorner || idx === 0 || idx === segmentWaypoints.length - 1 || idx % 2 === 0
  );
  return await routingAdapter(decimated, false);
}

function stitchSegments(segments) {
  const result = [];
  for (const seg of segments) {
    if (!seg || seg.length === 0) continue;
    for (const pt of seg) {
      if (
        result.length === 0 ||
        haversineDistanceM(result[result.length - 1], pt) > 1.5
      ) {
        result.push(pt);
      }
    }
  }
  return result;
}

function pruneSpursAndSpikes(routePoints, originalAnchors, maxSpurLengthM = 85) {
  if (routePoints.length < 4) return routePoints;

  const cornerAnchors = originalAnchors.filter((a) => a.isCorner);
  let pts = [...routePoints];
  let modified = true;
  let pass = 0;

  while (modified && pass < 3) {
    modified = false;
    pass++;
    const nextPts = [];
    let i = 0;

    while (i < pts.length) {
      let prunedJumpIndex = -1;
      let cumDist = 0;

      for (let j = i + 2; j < Math.min(pts.length, i + 18); j++) {
        cumDist += haversineDistanceM(pts[j - 1], pts[j]);
        if (cumDist > maxSpurLengthM * 2) break;

        const closureDist = haversineDistanceM(pts[i], pts[j]);
        if (closureDist < 14 && cumDist > closureDist * 3.2) {
          const midIdx = Math.floor((i + j) / 2);
          const tipPt = pts[midIdx];
          const isIntentionalCorner = cornerAnchors.some(
            (anchor) => haversineDistanceM(anchor, tipPt) < 22
          );

          if (!isIntentionalCorner) {
            prunedJumpIndex = j;
          }
        }
      }

      if (prunedJumpIndex !== -1) {
        nextPts.push(pts[i]);
        i = prunedJumpIndex + 1;
        modified = true;
      } else {
        nextPts.push(pts[i]);
        i++;
      }
    }
    pts = nextPts;
  }

  return pts;
}

/* ==========================================================================
 * Similarity & Geometric Math Functions
 * ========================================================================== */

export function evaluateShapeSimilarity(targetPattern, routedPath) {
  if (!routedPath || routedPath.length < 2) return 0;

  const N = 64;
  const normTarget = resampleGeoToNormalized2D(targetPattern, N);
  const normRouted = resampleGeoToNormalized2D(routedPath, N);

  const frechet = discreteFrechetDistance(normTarget, normRouted);
  const dirSim = averageTangentSimilarity(normTarget, normRouted);

  const distanceScore = Math.max(0, 100 * Math.exp(-3.2 * frechet));
  const directionScore = Math.max(0, ((dirSim + 1) / 2) * 100);

  return Math.round(0.65 * distanceScore + 0.35 * directionScore);
}

export function haversineDistanceM(a, b) {
  const dLat = (b.lat - a.lat) * DEG_TO_RAD;
  const dLng = (b.lng - a.lng) * DEG_TO_RAD;
  const lat1 = a.lat * DEG_TO_RAD;
  const lat2 = b.lat * DEG_TO_RAD;

  const sinDLat = Math.sin(dLat / 2);
  const sinDLng = Math.sin(dLng / 2);
  const h =
    sinDLat * sinDLat +
    Math.cos(lat1) * Math.cos(lat2) * sinDLng * sinDLng;
  return 2 * EARTH_RADIUS_M * Math.asin(Math.min(1, Math.sqrt(h)));
}

export function computeGeoPathLength(geoPoints) {
  let total = 0;
  for (let i = 1; i < geoPoints.length; i++) {
    total += haversineDistanceM(geoPoints[i - 1], geoPoints[i]);
  }
  return total;
}

function compute2DLength(pts) {
  let len = 0;
  for (let i = 1; i < pts.length; i++) {
    len += Math.hypot(pts[i].x - pts[i - 1].x, pts[i].y - pts[i - 1].y);
  }
  return len;
}

function interpolateAlong2DPolyline(pts, targetDist) {
  if (targetDist <= 0) return pts[0];
  let acc = 0;
  for (let i = 1; i < pts.length; i++) {
    const segLen = Math.hypot(pts[i].x - pts[i - 1].x, pts[i].y - pts[i - 1].y);
    if (acc + segLen >= targetDist) {
      const t = segLen > 1e-9 ? (targetDist - acc) / segLen : 0;
      return {
        x: pts[i - 1].x + t * (pts[i].x - pts[i - 1].x),
        y: pts[i - 1].y + t * (pts[i].y - pts[i - 1].y),
      };
    }
    acc += segLen;
  }
  return pts[pts.length - 1];
}

function simplifyRDP(points, epsilon) {
  if (points.length <= 2) return points;
  let maxDist = 0;
  let index = 0;
  const start = points[0];
  const end = points[points.length - 1];

  for (let i = 1; i < points.length - 1; i++) {
    const d = perpendicularDistance2D(points[i], start, end);
    if (d > maxDist) {
      index = i;
      maxDist = d;
    }
  }

  if (maxDist > epsilon) {
    const left = simplifyRDP(points.slice(0, index + 1), epsilon);
    const right = simplifyRDP(points.slice(index), epsilon);
    return left.slice(0, left.length - 1).concat(right);
  }
  return [start, end];
}

function perpendicularDistance2D(pt, lineStart, lineEnd) {
  const dx = lineEnd.x - lineStart.x;
  const dy = lineEnd.y - lineStart.y;
  const mag = Math.hypot(dx, dy);
  if (mag < 1e-9) return Math.hypot(pt.x - lineStart.x, pt.y - lineStart.y);
  const u = ((pt.x - lineStart.x) * dx + (pt.y - lineStart.y) * dy) / (mag * mag);
  const clampedU = Math.max(0, Math.min(1, u));
  return Math.hypot(pt.x - (lineStart.x + clampedU * dx), pt.y - (lineStart.y + clampedU * dy));
}

function resampleGeoToNormalized2D(geoPoints, numSamples) {
  const cosLat = Math.cos(geoPoints[0].lat * DEG_TO_RAD);
  const pts2D = geoPoints.map((p) => ({
    x: p.lng * cosLat,
    y: p.lat,
  }));
  const { normalizedPoints, normArcLength } = normalizeCanvasGeometry(
    pts2D.map((p) => ({ x: p.x, y: -p.y }))
  );
  const sampled = [];
  for (let i = 0; i < numSamples; i++) {
    const d = (i / (numSamples - 1)) * normArcLength;
    sampled.push(interpolateAlong2DPolyline(normalizedPoints, d));
  }
  return sampled;
}

function discreteFrechetDistance(P, Q) {
  const n = P.length;
  const m = Q.length;
  const ca = Array.from({ length: n }, () => new Float64Array(m).fill(-1));

  function c(i, j) {
    if (ca[i][j] > -0.5) return ca[i][j];
    const d = Math.hypot(P[i].x - Q[j].x, P[i].y - Q[j].y);
    if (i === 0 && j === 0) {
      ca[i][j] = d;
    } else if (i > 0 && j === 0) {
      ca[i][j] = Math.max(c(i - 1, 0), d);
    } else if (i === 0 && j > 0) {
      ca[i][j] = Math.max(c(0, j - 1), d);
    } else {
      ca[i][j] = Math.max(Math.min(c(i - 1, j), c(i - 1, j - 1), c(i, j - 1)), d);
    }
    return ca[i][j];
  }
  return c(n - 1, m - 1);
}

function averageTangentSimilarity(P, Q) {
  let sumCos = 0;
  let count = 0;
  const len = Math.min(P.length, Q.length);
  for (let i = 0; i < len - 1; i++) {
    const dx1 = P[i + 1].x - P[i].x, dy1 = P[i + 1].y - P[i].y;
    const dx2 = Q[i + 1].x - Q[i].x, dy2 = Q[i + 1].y - Q[i].y;
    const m1 = Math.hypot(dx1, dy1), m2 = Math.hypot(dx2, dy2);
    if (m1 > 1e-6 && m2 > 1e-6) {
      sumCos += (dx1 * dx2 + dy1 * dy2) / (m1 * m2);
      count++;
    }
  }
  return count > 0 ? sumCos / count : 0;
}

export function createOsrmShapeAdapter(
  osrmBaseUrl = 'https://router.project-osrm.org',
  profile = 'foot'
) {
  return async function osrmAdapter(waypoints, isMatchMode) {
    const coordsStr = waypoints
      .map((p) => `${p.lng.toFixed(6)},${p.lat.toFixed(6)}`)
      .join(';');

    if (isMatchMode && waypoints.length >= 3) {
      let currentTimestamp = 1700000000;
      const timestamps = [currentTimestamp];
      const radiuses = [waypoints[0].isCorner ? 25 : 50];

      for (let i = 1; i < waypoints.length; i++) {
        const dist = haversineDistanceM(waypoints[i - 1], waypoints[i]);
        currentTimestamp += Math.max(1, Math.round(dist / 1.4));
        timestamps.push(currentTimestamp);
        radiuses.push(waypoints[i].isCorner ? 25 : 55);
      }

      const url =
        `${osrmBaseUrl}/match/v1/${profile}/${coordsStr}` +
        `?overview=full&geometries=geojson&gaps=ignore&tidy=true` +
        `&radiuses=${radiuses.join(';')}&timestamps=${timestamps.join(';')}`;

      const res = await fetch(url);
      if (res.ok) {
        const data = await res.json();
        if (data.code === 'Ok' && data.matchings && data.matchings.length > 0) {
          const mergedCoords = [];
          for (const m of data.matchings) {
            for (const [lng, lat] of m.geometry.coordinates) {
              mergedCoords.push({ lat, lng });
            }
          }
          if (mergedCoords.length >= 2) return mergedCoords;
        }
      }
    }

    const routeUrl =
      `${osrmBaseUrl}/route/v1/${profile}/${coordsStr}` +
      `?overview=full&geometries=geojson&continue_straight=false`;
    const res = await fetch(routeUrl);
    if (!res.ok) throw new Error(`OSRM HTTP status: ${res.status}`);
    const data = await res.json();
    if (data.code !== 'Ok' || !data.routes?.[0]) {
      throw new Error(`OSRM error code: ${data.code}`);
    }
    return data.routes[0].geometry.coordinates.map(([lng, lat]) => ({ lat, lng }));
  };
}
```
